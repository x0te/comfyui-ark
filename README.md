# ComfyUI Ark

ComfyUI 워크플로우 아카이브를 다른 PC의 ChatGPT와 공식 ComfyUI MCP로 구축하기 위한 자료입니다.

## Files

- `ComfyUI_Ark_Exact_Model_Maintenance_List_v8.md` — 정확한 세부 모델을 기준으로 정리한 378개 유지 대상 워크플로우 목록
- `ComfyUI_Ark_Autonomous_Setup_Prompt_KO.md` — 새 PC에서 설치, 모델 다운로드, 커스텀 노드 설치, 실행 검증, 한국어 설명 삽입을 지시하는 프롬프트

## Use on another PC

1. 이 저장소를 내려받습니다.
2. ChatGPT에 공식 ComfyUI MCP와 로컬 파일·터미널 접근을 연결합니다.
3. 위 두 Markdown 파일을 같은 대화에 첨부합니다.
4. `ComfyUI_Ark_Autonomous_Setup_Prompt_KO.md`의 구분선 아래 프롬프트 전체를 전송합니다.

저장소는 회사 자료 보호를 위해 비공개로 유지하는 것을 권장합니다.
